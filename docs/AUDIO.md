# Web Audio API Procedural Lo-Fi Synthesizer

HyFly-4 synthesizes all audio in real-time via Web Audio API nodes:
- Lo-Fi Electric Piano: Polyphonic sine and triangle oscillator chords.
- Vinyl Surface Noise: Procedural white noise buffer with biquad bandpass filter.
- Footsteps: Synthesized wooden contact clicks pitched to surface material.
- SFX: Mechanical relays, water streams, and chime bells.
