# HyFly-4 User Input and Controls Reference

## Locomotion
- W / Arrow Up: Move forward
- S / Arrow Down: Move backward
- A / Arrow Left: Turn / Strafe left
- D / Arrow Right: Turn / Strafe right
- Shift: Sprint (1.75x velocity)
- Spacebar: Jump

## Gestures & Flight
- [1] Wave Hand emote
- [2] Cast Spell emote
- [3] / F: Broom Flight mode
- [4] Read Book emote
- [5] Polite Bow emote
- [6] Sit Down emote (lounge on sofa or terrace)
- V: Cycle camera view (Full Body, Top-Down, Portrait, First-Person POV)

## Camera & Utilities
- V: Cycle camera view (Full Body, Top-Down, Portrait)
- P: Toggle Photo Mode (Clean view without UI)
- E / Left Click: Interact with nearby appliances
